# v2.2.0

실제 Pterodactyl 환경 테스트를 거친 **Pterodactyl Minecraft Multi-Profile Manager** 정식 안정화 릴리스입니다.

## 주요 변경점

- 한글/Unicode 프로필 이름 지원
- `profile.conf` 자동 생성
- `logs/latest.log`, `versions/`, JAR 이름/구조 기반 기존 서버 자동 감지 강화
- Java 8 / 11 / 16 / 17 / 21 / 25 자동 선택 및 캐시
- Pterodactyl `Memory=0 (Unlimited)` 정상 처리
- Primary Allocation 포트 자동 적용
- 프로필 전환 시 이전 프로필 자동 백업
- 실제 환경에서 `BACKUP_KEEP` 보관 개수 검증
- 존재하지 않는 프로필 안전 차단
- 대용량 파일 업로드 권장 방식으로 Pterodactyl `Launch SFTP` + WinSCP 문서화
- 실험용 동적 Startup 드롭다운 / Panel 패치 제거

## 실제 환경 검증

신규 실행, 한글 프로필, Paper 1.21.11 + Java 21, Paper 26.2 + Java 25, Java 자동 전환, 프로필 백업, 백업 보관 개수, 잘못된 프로필 차단, 실제 Minecraft 클라이언트 접속, 프로필 왕복 후 월드 유지까지 확인했습니다.

## AI 사용 공개

설계, 코드 작성/수정, 디버깅, 문서화, 릴리스 준비 과정에서 OpenAI ChatGPT를 사용했습니다. 최종 기능 선택, 실제 환경 테스트, 배포 및 저장소 관리는 프로젝트 소유자가 수행합니다.
