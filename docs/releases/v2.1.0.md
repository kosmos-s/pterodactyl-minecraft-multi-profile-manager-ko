# v2.1.0

**Pterodactyl Minecraft Multi-Profile Manager**의 첫 공개 릴리스입니다.

## 주요 기능

- Pterodactyl 서버 1개와 Primary Allocation 1개로 여러 Minecraft 서버 폴더를 보관하고 하나씩 실행
- `SERVER_PROFILE`로 실행할 프로필 전환
- `profile.conf`이 없으면 자동 생성
- Paper, Purpur, Folia, Spigot, Vanilla, Fabric, Quilt, Forge, NeoForge, Mohist, Magma, Arclight 등 일반적인 서버 구조 자동 감지
- 가능한 경우 Minecraft 버전 자동 감지
- Java 8, 11, 16, 17, 21, 25 런타임 자동 선택 및 캐시
- 프로필별 설정 자동 적용
- 애매하거나 잘못된 프로필은 임의 실행하지 않고 안전하게 중단
- 프로필 전환 시 이전 프로필 자동 백업
- 선택된 프로필에 현재 Pterodactyl Primary Allocation 포트 자동 적용
- 선택 사항: `/servers` 폴더를 읽어 `SERVER_PROFILE`을 동적 드롭다운으로 표시하는 Panel 패치

## 포함 파일

- `egg/egg-minecraft-multi-profile-manager-v2.1.json`
- Startup 동적 프로필 드롭다운 Panel 패치
- Panel 패치 설치 / 제거 스크립트
- v1 → v2 마이그레이션 문서
- MIT License

## 주의사항

- 한 번에 프로필 하나만 실행하는 용도로 설계했습니다.
- 동적 드롭다운은 Pterodactyl Panel 프론트엔드를 수정하므로 Panel 업데이트 후 다시 적용해야 할 수 있습니다.
- 프로필 백업은 `.tar.gz` 파일이며 Pterodactyl 기본 Backups 탭과는 별도입니다.
- 중요한 Minecraft 월드는 별도의 외부 백업도 유지하는 것을 권장합니다.
